# SERENO

**Alerta de ventana de infeccion de roya del cafe, por parcela, con dias de anticipacion.**

Cuando el caficultor ve las manchas anaranjadas, la infeccion ocurrio hace 25-30
dias y el fungicida ya es dinero tirado. Las condiciones que la causan —horas de
hoja mojada dentro de un rango de temperatura— **se ven venir en el pronostico**.
